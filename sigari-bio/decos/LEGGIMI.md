# Decorazioni a immagine

Qui vanno le decorazioni nuove (una per file): `<id>.webp` (o `.png`), quadrate, sfondo trasparente,
cerchio centrale vuoto (72% della larghezza).

Gli id e le animazioni sono in `../decos.js` (`DECO_IMG`). Una decorazione compare nella dashboard
solo quando il suo `ready` è `true`.

I prompt per generarle sono nel cervello: `output/2026-11-10-decorazioni-18k-prompt.md`.
